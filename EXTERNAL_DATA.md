# External data and raw reconstruction boundary

This archive deliberately omits large online files and data whose source terms must be assessed separately. It supplies the analysis-ready transformations and identifiers needed for all reported statistical comparisons. A reader attempting the raw-source-to-panel rebuild should use the **same versions and file names**, not current default versions.

|---|---|---|---|

The original processing fixes valid-pixel support through time and uses `all_touched=True`. EOG totals exclude invalid pixels using its frozen all-year support. Black Marble uses the `AllAngle_Composite_Snow_Free` layer, `Quality == 0`, observation count `> 3`, land-water mask `{0,1,2,5}`, and low positive radiance `[0,0.5)` set to zero; see `provenance/ROUND10B_A_BLACK_MARBLE_PROTOCOL.md` for an additional Black Marble support audit. The processed light CSVs preserve counts, masks, product version and source provenance by prefecture-year. Re-downloading a later reprocessed raster or collection may not reproduce the frozen series.

The original local raw-raster extraction scripts depended on a separate source workbook, cached third-party boundaries and authenticated HDF files, and are **not** represented as a one-command stage in this archive. The provided one-command runner starts at the certified analysis panel. This is an explicit reproducibility boundary, not a claim that raw-source reconstruction was rerun during packaging.
