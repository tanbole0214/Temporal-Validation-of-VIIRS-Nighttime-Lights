# Public and restricted materials

Included: author statistical code; annual/pooled aggregate metrics; aggregate loss intervals and source-audit rates; submitted Table 3; environment/version information; statistical-input hashes; verification instructions.

Excluded: the Markdata workbook and third-party publications; city-year outcomes and analysis panels; individual predictions and losses; bootstrap loss draws; sampled city-year verification ledger; detailed acquired-source inventory; raster/boundary files; credentials; personal browser data; dependencies/runtimes and junctions; unpublished manuscript files.

The workbook-versus-official scatter SVG is excluded because vector point geometry may approximately reveal observations. Removing an Excel file alone does not ensure that derivatives reveal no row-level values.

The public layer supports summary replay without restricted inputs. Refitting requires separately obtained exact statistical inputs and permission. The paper's substantive method, data-source qualifications and empirical conclusions are not obscured by this separation. No false licence, DOI, full-public-reproduction claim or automatic reviewer-access entitlement is created.
